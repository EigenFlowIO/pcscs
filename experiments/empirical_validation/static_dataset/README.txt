PCSCS HUMAN-CURATED STRUCTURED PROBE SAMPLE

This archive contains exactly 250 preserved-specimen images.

Each included image was individually reviewed by a human curator.

Review interaction:
    Y = retain image
    N = reject image

Only exact-media records with CC0 or CC BY licenses were admitted.

Exact duplicate image byte streams were rejected automatically
using SHA-256 before human review.

The sample is an analytical probe for examining neural-network
internal representation geometry. It is not a biological
classification benchmark.

Contents:

    images/
        Exact frozen image bytes.

    sample_manifest.csv
        Full sample and provenance table.

    sample-manifest.json
        Machine-readable manifest.

    IMAGE_LICENSES.csv
        Rights, license, attribution, and source metadata.

    human_rejections.csv
        Candidate images rejected during visual inspection.

    automatic_skips.csv
        Duplicate, invalid, undersized, or inaccessible images
        rejected automatically.

    dataset-metadata.json
        Dataset summary.

    config.json
        Acquisition and curation policy.

    checksums.sha256
        Integrity hashes for all frozen dataset files.
